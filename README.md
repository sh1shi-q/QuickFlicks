# QuickFlicks

A movie ticket booking platform with a modern, responsive design.

## Features

- Movie ticket booking system
- Theater browsing and showtimes
- User authentication (Login/Register)
- User dashboard for bookings
- Responsive design for all devices
- Dark theme with smooth animations

## Technologies

- Java (JSP/Servlets)
- Bootstrap 5
- MySQL Database
- HTML5 & CSS3
- JavaScript

## Getting Started

### Prerequisites
- Java JDK 8 or higher
- Apache Tomcat
- MySQL Database

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sh1shi-q/QuickFlicks.git
   ```

2. Configure database connection in the application

3. Deploy to Tomcat server

4. Access the application at `http://localhost:8080/QuickFlicks/`
